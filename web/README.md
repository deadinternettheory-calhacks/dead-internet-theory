# dead internet theory web

React, TypeScript, and Vite application. The Vercel project root is `web/`.

## Commands

```sh
npm install
npm run dev
npm run lint
npm test
npm run build
```

## Connecting the analysis API

`VITE_API_BASE_URL` sets the public base URL that the analysis page calls for
the v1 routes. It is a URL, not a secret; never put tokens or API keys in a
`VITE_*` variable.

The ingestion backend ([../backend/INTEGRATION.md](../backend/INTEGRATION.md))
requires a bearer JWT on every route and does not allow cross-origin browser
calls. `VITE_API_BASE_URL` must therefore point at a trusted same-origin
proxy/BFF that attaches a frontend token and forwards to the backend. That
proxy and its token issuance are an open team decision and are not built yet.

- **Not set:** the analysis page shows the honest "service not connected" state.
- **Set:** submitting a link creates an investigation (`POST /v1/investigations`),
  polls its real `ingestionStatus` and `analysisStatus`, then fetches the stored
  analysis, graph and used enrichment jobs and renders the report. Ingestion
  failures, analysis failures and unsupported links each get their own message;
  no result is shown for a failed analysis.

## Synthetic example

`/example` renders a finished report from `src/demo/synthetic-report.json`,
labeled as synthetic. That file is generated by `npm run demo` in `inference/`,
which runs the real inference pipeline on a fabricated discussion with recorded
CREAO responses; do not edit it by hand. Reports built from synthetic
fixtures show a banner and never link to the made-up source URLs.

## Report

`src/analysis/report.ts` turns the v1 `AnalysisResource` and graph into the
page's sections, in the SPEC 4.2 order: post, plain-language result, up to three
findings with quoted evidence, detailed analysis, then coverage and limitations.
The coordination index appears only inside the detailed analysis, labeled as an
uncalibrated heuristic. Types in `src/api/contract.ts` mirror only the fields
the UI reads; the canonical models are in `../contracts/`.

## Routing

Vercel `web/vercel.json` rewrites paths to the SPA entry point for refresh and shortcut links. Prefix URLs preserve nested path and query strings. A browser does not send an unencoded `#fragment` to the server; to preserve one, encode the complete source URL as the shortcut path segment first. Hash fragments are not needed to identify an ordinary post and the raw form cannot preserve them.
