Extension privacy

Dead Internet Theory helps you inspect public social discussions for patterns of coordinated promotion.

What the extension reads

Clicking the toolbar icon reads the current tab’s URL. The right-click action reads the selected link. You can also paste a link. Selected supported links are saved locally so you can resume your work. The extension does not access Chrome’s browsing-history database, monitor other pages as you browse, read page contents, private messages or passwords, or automatically analyze pages.

What is sent

Pressing Analyze post sends the selected public post URL to https://www.deadinternettheory.us. The service retrieves public discussion data through Apify, stores application data in Convex, and uses Anthropic Claude and/or CREAO for analysis. This data includes public post and comment text, source links, usernames and available public profile metadata. Bounded public account histories may be sampled on supported platforms. Collection can be incomplete. Provider credentials stay on the server.

The extension also requests service availability and investigation status/results from that website. A randomly generated anonymous session credential is sent with these requests; the service hashes it to identify the investigations belonging to this installation. It is not a social-platform login or password. HTTPS requests expose network metadata such as your IP address, request time and browser-provided headers to the website’s hosting service, Vercel. The extension does not request GPS or device geolocation.

The extension adds no advertising or analytics trackers and does not log mouse movements, keystrokes, scrolling or clicks on websites. Buttons and keyboard shortcuts inside the extension are handled locally to operate its interface and animated ghost.

Use and sharing

Selected links and public discussion data are used to provide the analysis you request and its reports. Vercel hosts the website/API, Convex stores and coordinates application data, Apify collects public source data, and Anthropic Claude and/or CREAO process bounded evidence for analysis. These service providers receive the data needed for their respective roles.

Our use and transfer of information received through Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. We do not sell user data, use or transfer it for advertising or purposes unrelated to the extension’s single purpose, or use it to determine creditworthiness or for lending.

Local storage

A random anonymous session credential lets the extension read its own investigations. It is stored locally in the extension and is not a personal login. At most ten investigation links, IDs, request keys and expiry times are kept locally, for up to 24 hours. An expiry alarm removes expired metadata while Chrome runs; startup also removes it. Report contents and collected comments are not saved in extension storage.

Clear saved links removes that local investigation metadata. It does not cancel work already running on the server or shorten the server’s retention period. Uninstalling the extension removes its local data and session credential.

Server retention

Live application reports and source data have a fixed 24-hour expiry. Reuse does not extend it. Owned Apify resources enter a deletion queue with retries. Provider internal copies, logs and backups have separate retention controls. Closing the panel does not cancel a submitted investigation.

Permissions

activeTab reads the URL when invoked; sidePanel displays the panel; contextMenus adds the link action; storage saves the anonymous session and expiring investigation metadata; alarms expires that metadata. Host access is restricted to https://www.deadinternettheory.us for analysis requests. The extension does not request persistent access to social sites.
