Dead Internet Theory — Chrome extension

1. Extract this ZIP into a folder.
2. Open chrome://extensions in Chrome 123 or newer.
3. Enable Developer mode.
4. Click Load unpacked and select the folder containing manifest.json.
5. Pin the ghost icon from Chrome's extensions menu.

Open a public Reddit, X, TikTok or YouTube post and click the ghost.
Keyboard shortcut: Ctrl+Shift+Y (Command+Shift+Y on macOS).
Alternatively, right-click a post link and choose Analyze with Dead Internet Theory.
Review the selected link, then click Analyze post.

You can close the panel while the server works. Reopen it to resume.
Open full report displays the same investigation in an extension tab; it does
not submit the post again. No API keys or other settings are needed.

Read privacy.html for data handling. This ZIP is for unpacked installation;
it has not been published to the Chrome Web Store.
